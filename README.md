# 标签筛选牌组（Anki 插件）

按标签的**并集**或**交集**把卡片挑出来，建成本地原生筛选牌组。

因为用的是 Anki 自己的筛选牌组机制，所以：

- 筛选牌组里的卡和原卡是**同一张卡**，复习记录、排期、间隔全部共享；
- 在里面作答会按你选的顺序**重排原卡**（固定开启）；
- **删除筛选牌组只把卡送回原来的牌组**，卡片和复习记录都不会丢。

## 安装

双击 `tag_filtered_deck.ankiaddon`，或在 Anki 里「工具 → 插件 → 从文件安装…」，
装完重启 Anki。菜单「工具 → 标签筛选牌组…」进入管理窗口。

需要桌面版 Anki 26.9.x（在 26.9.3 上开发和验证），界面为中文。

## 入口

- 工具菜单 →「标签筛选牌组…」：管理窗口，可新建、编辑、集中刷、立即重收、删除
  （要改牌组位置，在「编辑」里改「牌组位置」）。
- 卡片浏览器左侧标签上点右键 →「用它创建标签筛选牌组…」。
- 牌组列表里筛选牌组右侧齿轮 / 右键 →「编辑筛选规则…」「立即重建」「集中刷…」
  「删除筛选（保留卡片）」。

## 规则

**标签**（至少 1 个）两种加法随便用：手打（带已有标签自动补全），
或右侧常驻的「已有标签」面板（搜索后点选、Ctrl/Shift 多选、双击加入）。

其余：并集 / 交集、取卡范围、牌组位置、牌组名、收录顺序、单次上限。
层级标签自动包含子标签（例如 `唐诗` 也匹配 `唐诗::格律`）。
规则保存在当前用户配置里，按牌组 ID 索引，切换用户配置互不干扰。

**取卡范围**是三个可点选的状态，默认三个都勾，至少勾一个：

| 选项 | 搜索词 | 含义 |
| --- | --- | --- |
| 未学习 | `is:new` | 完全没学过的新卡 |
| 学习中 | `is:learn` | 正在学，含答错后正在重学的卡 |
| 复习中 | `is:review -is:learn` | 已毕业、进入间隔复习的卡 |

三项互不重复，相加正好等于命中总数。另有默认不勾的「连还没到期的也收（集中突击用）」：

- 不勾（＝**只收到期**）：只收到期的卡加新卡，这样学完的卡不会在下次重收时被拉回来。
  「到期」按**卡片自己的到期时间**算（筛选牌组里读卡片的原始到期日 `odue`），
  不叠加原牌组的每日新卡/复习上限；还没学过的新卡不受这个开关影响。
- 勾上（＝**突击牌组**）：连还没到期的卡也一起收，适合集中突击。这类牌组
  **不会自动重收**（进牌组、启动 Anki 都不收），这样一轮才刷得完；
  想重新装满就点「立即重新收卡」，或者直接用下面的「集中刷…」。

**为什么没有「已暂停 / 已搁置」选项**：Anki 重建筛选牌组时一定会把搜索式拼成
`<你的条件> -is:suspended -is:buried -deck:filtered`（在 Anki 26.9.3 上实测确认），
暂停/搁置的卡不先解禁就永远收不进来，而解禁又会改动你卡片的暂停状态。
本插件**绝不修改卡片状态**，改为在预览里提示「这类卡这次收不进来多少张」。
编辑器的「看收不进来的卡」列出的就是这批收不进来的卡（还没到期、被暂停/搁置、
已在别的筛选牌组里），张数与预览一致；它是按卡片号（`cid:` 列表）查的，超过 5000 张
会只列前面一部分并在标题里写明。

## 集中刷（点一下刷一轮没到期的卡）

集中刷是**临时动作**，不是规则里的开关，也**不改规则本身**：入口在管理窗口的
「集中刷…」，或牌组右键的「集中刷…（临时把没到期的也收进来，突击一轮）」。点完先问
一句「这次要不要影响原卡排期」：

- **不影响排期（推荐）**——按 Anki 预览模式刷。原卡的到期时间、间隔、因子、次数和
  正式复习记录都不变（Anki 会额外记一条集中刷预览日志）；答「重来」按**卡片自己
  原牌组**里设的新卡学习步骤的第 1 步延迟回来（默认 1 分钟），答「困难」按新卡算法
  值（默认 5.5 分钟）回来，答「良好 / 简单」这张卡就算刷完、带着原来的到期时间回
  原牌组。对话框里会写明延迟来自哪个原牌组；卡片来自多个原牌组时取张数最多的那个，
  并提示还有多少张来自别的原牌组。
- **影响排期**——收录范围一样放宽，作答按算法写回原卡，等于正常学习一遍。
  注意：还没到期的「复习中」卡，Anki 算出的新间隔不会比原来短，所以这种卡在
  「影响排期」下刷了基本等于没刷，要突击它们请用「不影响排期」。

两种模式都只临时忽略「是否到期」；暂停/搁置、已在别的筛选牌组里的卡照旧收不进来
（Anki 硬限制），对话框里会先报数量。任何被托管的筛选牌组都能用集中刷。

一次点击＝**一轮**。它会**另建**一个 `原牌组名·集中刷` 的临时筛选牌组（原筛选牌组的
设置一个字都不动，只是暂时显示 0 张），并弹一个「集中刷 · 牌组名」小窗，写着模式、
这次收进多少张（其中多少张是没到期临时拉进来的）、第几轮、开始时间，以及
「去刷题」「再刷一轮」「结束集中刷（恢复正常筛选牌组）」按钮。

点完之后主窗口**直接进这个牌组的答题界面**开刷（第一次点就能进，不用先回牌组列表），
小窗待在主窗口后面、不抢焦点；想把它调回前面，在管理窗口或牌组右键点
「打开集中刷窗口」。「去刷题」也是同一个落点。

**关掉这个小窗（× 或 Esc）就等于结束这一轮**：删掉临时牌组（卡回原牌组）→
按原规则重建原筛选牌组 → **界面当场刷新**（1.5.1／1.5.2 修的：以前数据已经恢复，
只是界面停在旧画面；在牌组列表上结束时，列表里还留着已经删掉的临时牌组、原牌组
张数也是旧的）。想接着突击就点「再刷一轮」
（重建临时牌组、轮次 +1），点几次刷几轮。刷的时候想先去别的牌组看看，会先问你
「要不要结束集中刷」，选「继续」就保持原样。关掉 Anki 重开也会自动结束
（下次启动自动删掉残留的临时牌组）。集中刷期间原牌组和临时牌组的自动重收都会跳过，
免得刷到一半卡被收走。

## 自动重收与更新

管理窗口底部三个勾选框：

- 「进入牌组时自动重新收卡（并在 Anki 启动时各收一次）」——默认打开；
- 「启动时自动检查更新（每天最多一次）」——默认打开；
- 「让 Anki 也自动检查插件更新」——读写 Anki 自己的设置，插件不替你改。

注意：「连还没到期的也收」的突击牌组不参与自动重收（它保持现状），
想重新装满点「立即重新收卡」或「集中刷…」。

「检查更新（GitHub）」从公开仓库 `creeperboo/anki-tag-filtered-deck` 取 `version.txt`
比版本号，有新版本才问你要不要下载安装（raw 优先，失败退回 Release 附件），
装完提示重启 Anki。除这个联网动作外插件不联网，也不改动卡片内容。

## 日志与排错

- 插件自己的运行日志是插件目录下的 `user_files\log.txt`，管理窗口底部的
  「打开日志文件」可以直接打开。
- 所有菜单和钩子都做过防护：插件内部出错只写日志，不会再弹 Anki 的「遇到了问题」。
  1.5.2 还把后台操作的返回值改成了 Anki 原生结果——以前操作明明成功了，也会弹
  「遇到了问题…可能是由某一插件引起」。
- 管理窗口底部会显示一行「最近一次致命异常指向 某插件 · 时间」（读 Anki 的
  `crash.log`）。显示本插件就说明是本插件引起的，显示别的插件则与本插件无关。

## 源码与测试

- `源码\`：插件源码（`__init__.py` + `rule_logic.py`），打包进 `.ankiaddon` 的就是这些。
- `源码\tests\test_rule_logic.py`：纯逻辑测试，不需要 Anki。
  `python -m unittest discover -s 源码\tests -p "test_*.py"`。
- `工具\run_anki_probe.py`：在临时用户配置里启动真实 Anki 的隔离集成探针
  （`--from-ankiaddon` 可改为验证成品包）。
- `安装到Anki.py`：重新打包 `.ankiaddon` 与源码包，可选安装到本机 `addons21`。

详细操作见 `操作指南.txt`，开发者说明见 `项目说明.md`。
