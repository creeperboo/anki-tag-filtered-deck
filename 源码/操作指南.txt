标签筛选牌组 · 操作指南
========================

插件做的事：把带某些标签的卡片，用 Anki 原生的「筛选牌组」临时挑出来单独复习。
它不会复制卡片，所以：
  * 筛选牌组里的卡和原卡是同一张，复习记录、排期完全共享；
  * 在筛选牌组里作答，会按你选的顺序重排原卡；
  * 删掉筛选牌组，卡片会回到各自原来的牌组，一张都不会丢。


一、新建一个标签筛选牌组
------------------------

最快的方法（推荐）：
  1. 打开「浏览」（卡片浏览器）；
  2. 在左侧列表里找到「标签」小节，找到你要的标签；
  3. 在那个标签上点右键，选「用它创建标签筛选牌组…」；
  4. 窗口里已经帮你选好这个标签，按需要再补充，点「创建并收卡」。

从菜单新建：
  1. 菜单「工具 → 标签筛选牌组…」；
  2. 点「新建」；
  3. 选标签，两种方式随便用：
       · 左边「手打添加」：输入标签后按回车或点「添加」，输入时会有已有标签的
         补全提示；要删掉某个标签，双击它，或者选中后按 Delete 键；
       · 右边「已有标签」面板：在搜索框里输入关键词（大小写不敏感、包含匹配），
         在列表里点选（按住 Ctrl / Shift 可以多选），点「加入所选」；
         也可以直接双击某个标签把它加进左边；
     右下角会显示「已选 N 个标签」。
  4. 选「标签关系」：
       · 并集：命中任意一个标签就收（例如同时收「唐诗」和「宋词」）；
       · 交集：要同时带全部标签才收（例如既是「唐诗」又是「重点」）；
     注意：层级标签自动包含子标签。选了「唐诗」，带「唐诗::格律」的卡也会被收，
     这是 Anki 的 tag: 搜索规则本身的行为。
  5. 勾「取卡范围」——三个可以点着选的状态，默认三个都勾：
       · 未学习：完全没学过的新卡（is:new）；
       · 学习中：正在学、含答错后正在重学的卡（is:learn）；
       · 复习中：已经毕业、进入间隔复习的卡（is:review -is:learn）。
    三项互不重复，相加正好等于命中总数；至少要勾一个。
     下面的「连还没到期的也收（集中突击用）」默认不勾：
       · 不勾（＝只收到期）：只收到期的卡和新卡，学完的卡不会在下次重收时被拉回来；
       · 勾上（＝突击牌组）：连还没到期的复习卡也一起收；这类牌组不会自动重收
         （进牌组、启动 Anki 都不收），这样一轮才刷得完；想重新装满点「立即重新收卡」。
     「到期」是按卡片自己的到期时间算的（筛选牌组里读卡片自己的原始到期日），
     不叠加原牌组的每日新卡 / 复习上限；完全没学过的新卡不受这个开关影响。
     临时想突击刷没到期的卡，不用改规则，用「集中刷…」（见第三节）。
     「已暂停 / 已搁置」没有做成选项：Anki 重建筛选牌组时一定会排除这两类卡，
     而这个插件不会去改动你卡片的暂停状态。预览里会告诉你有多少张这样收不进来，
     想学它们请先在浏览器里取消暂停或取消搁置。
  6. 「牌组位置」默认放在「标签筛选」这个父牌组下面。想放别处可以直接选，
     也可以手输，路径用两个冒号分隔，例如「考研::英语」。
  7. 「牌组名」默认按标签自动生成，例如「唐诗 + 宋词」「唐诗 ∩ 宋词」；
     重名会自动加编号（2）、（3）。想自己起名直接改，点「按标签命名」可以还原。
  8. 「收录顺序」默认「到期顺序」；「单次收录上限」默认 9999。
  9. 窗口下面会实时显示预计收录多少张、命中总数里未学习/学习中/复习中各多少张，
     以及有多少张因为还没到期、被暂停/搁置、或已在别的筛选牌组里而收不进来。
 10. 点「创建并收卡」。

底部还有两个顺手的按钮：
  * 「在浏览器里看匹配的卡」——按规则命中、而且这次能收进来的卡；
  * 「看收不进来的卡」——这次收不进来的卡（还没到期、被暂停/搁置、或已经躺在
    别的筛选牌组里），张数和上面预览里写的那个数字一致；它按卡片号（cid 列表）
    查，一次最多列 5000 张，超过会在标题里写明。


二、日常使用
------------

* 从牌组列表点进这个筛选牌组，就会按规则自动重新收卡（只在进入总览页时做一次）。
  例外：勾了「连还没到期的也收」的「突击牌组」不自动重收——它保持现状，想重新
  装满点「立即重建」，或者用「集中刷…」。
* 学习中返回总览页不会重算，避免刚学完的卡立刻被拉回来。
* 想立刻重算：在牌组列表里点这个牌组右侧的齿轮选「立即重建」，
  或者右键牌组选「立即重建」，Anki 自带的「重建」按钮也一样能用。


三、集中刷（点一下刷一轮没到期的卡）
------------------------------------

这是一个「点一下就用一轮」的临时功能，不是规则里的开关，也不会改规则本身。

入口（两处）：
  * 管理窗口里选中那一行，点「集中刷…」；
  * 在牌组列表里右键该筛选牌组 →「集中刷…（临时把没到期的也收进来，突击一轮）」。

任何被托管的筛选牌组都能用集中刷；如果这个牌组正在集中刷，这两个入口会变成
「打开集中刷窗口」，点一下把那个小窗调回来。

点完会先问一句「这次要不要影响原卡排期」，有三个选择：

  * 不影响排期（推荐）——按 Anki 的预览模式刷：
      · 原卡的到期时间、间隔、因子、次数和正式复习记录都不会变；
        （Anki 会为这次集中刷额外记一条预览日志，不影响排期）
      · 答「重来」→ 按**卡片自己的原牌组**里设的新卡学习步骤第 1 步（默认 1 分钟）
        回到集中刷；答「困难」→ 按同一套步骤算出的新卡算法值（默认 (1+10)/2 = 5.5
        分钟）回到集中刷。对话框里会写明延迟来自哪个原牌组，卡片来自多个原牌组时
        取张数最多的那个，并提示还有多少张来自别的原牌组；
      · 答「良好 / 简单」→ 这张卡就算刷完了，带着原来的到期时间回原牌组。
  * 影响排期——收录范围一样放宽，但作答会按算法写回原卡排期，等于把没到期的卡
    当成正常学习刷一遍。注意：还没到期的「复习中」的卡，Anki 算出来的新间隔不会
    比原来的短，所以在「影响排期」下刷了基本等于没刷（只多一条记录）；要突击这类
    卡请用「不影响排期」。
  * 取消。

两种模式的共同点：
  * 只临时忽略「是否到期」这一条；标签、并集 / 交集、三个状态勾选都照旧；
  * 暂停 / 搁置的卡和已经在别的筛选牌组里的卡依然收不进来（Anki 本身的限制），
    对话框里会先告诉你预计能收多少张。

一次点击＝一轮。它会另外建一个名字叫「原牌组名·集中刷」的**临时筛选牌组**，把
符合规则、但还没到期的卡也收进去；你原来的那个筛选牌组的设置一个字都不会动，
只是暂时显示 0 张（卡都在临时牌组里）。

点完之后：主窗口**直接进这个牌组的答题界面**开刷，同时弹出一个标题是
「集中刷 · 牌组名」的小窗，小窗待在主窗口后面、不抢焦点，不挡你答题。
  * 小窗里写着这次是哪种模式、收进来多少张（其中多少张是没到期被临时拉进来的）、
    第几轮、开始时间，以及「去刷题」「再刷一轮」「结束集中刷（恢复正常筛选牌组）」
    三个按钮；
  * 「去刷题」＝把主窗口切回这个牌组的答题界面（第一次点就能进，不用先回牌组列表）；
  * 想看看这个小窗：在管理窗口点「打开集中刷窗口」，或在牌组列表里右键该牌组点
    「打开集中刷窗口」，它会被调到最前面；
  * 「再刷一轮」＝把临时牌组重新收满（含刚刷完的卡），轮次 +1。想接着突击就再点一次，
    点几次刷几轮，不会一直循环出不来；
  * 刷的时候不用管这个小窗，让它待在后面就行。

结束这一轮（三种方式，效果一样）：
  * 关掉那个小窗（右上角的 × 或者按 Esc）——这是最常用的方式，**关窗就等于结束**；
  * 在小窗里点「结束集中刷（恢复正常筛选牌组）」；
  * 关掉 Anki 再打开也会自动结束（下次启动按原规则收）。

结束时会先删掉那个临时牌组（里面的卡立刻回各自原牌组），再按你的规则重新收一遍，
牌组回到日常状态；主窗口也会当场回到**原筛选牌组的总览页**，牌组列表和总览页上的
张数立刻刷新，不会留下已经消失的临时牌组。
  * 不管你是从答题界面、总览页还是牌组列表结束这一轮，这三处都会当场刷新
    （1.5.2 修过：在牌组列表上结束时，列表以前不会重画，看着像没恢复）；
  * 如果你想刷着刷着先去别的牌组转一圈：一换到别的牌组就会先问你「要不要结束集中刷」，
    选「继续集中刷」就保持原样、小窗也留着；
  * 集中刷期间，原牌组和临时牌组的自动重收都会跳过，免得刷到一半卡被收走；
  * 已经在集中刷的牌组，再点一次「集中刷…」不会重复建，只是把那个小窗调出来。

集中刷只影响这个牌组本身：原筛选牌组的设置一个字都不改，别的牌组和别的规则也不受影响。


四、修改规则
------------

任选其一：
  * 菜单「工具 → 标签筛选牌组…」→ 选中那一行 →「编辑」；
  * 在牌组列表里右键该筛选牌组 →「编辑筛选规则…」；
  * 想换位置：在编辑窗口里改「牌组位置」那一栏。

改完保存，牌组会按新规则重新收卡；卡和复习记录不受影响。
牌组名改了就是重命名，牌组里的卡会跟着走。


五、"被 Anki 内置设置改过"是什么意思
------------------------------------

如果你用 Anki 自己的筛选牌组设置窗口改了条件，插件就认不出这是它上次写的那套设置，
于是会：
  * 跳过自动重收（不会静默覆盖你的修改）；
  * 在管理窗口把状态标成「被 Anki 内置设置改过，自动重收已暂停」，并在进入
    该牌组时弹一个提示。

想交回插件管理：在管理窗口选中它，点「编辑」，检查一下标签规则，保存即可。


六、删除
--------

「删除筛选（保留卡片）」只会删掉筛选牌组本身：
  * 里面的卡片会立刻回到各自原来的牌组；
  * 卡片内容、复习记录、排期都不会丢。

如果它不是筛选牌组（比如你把它变成了普通牌组），插件不会替你删——
因为删普通牌组会连卡片一起删掉，这个风险插件不碰。

手动用 Anki 删掉了筛选牌组也没关系：失效的规则会在下次打开用户配置时自动清理。


七、插件的设置
--------------

管理窗口底部有三个勾选框，改完立刻生效：

  * 「进入牌组时自动重新收卡（并在 Anki 启动时各收一次）」——默认打开。
      打开：从牌组列表进入筛选牌组总览页时按规则重收一次，Anki 启动后也各重收一次；
      关闭：这两种自动重收都不做，「立即重新收卡」按钮照旧能用；
      例外：勾了「连还没到期的也收」的突击牌组不管这个开关是开还是关，都不自动重收；
      不管是开还是关，条件被 Anki 内置设置改过的牌组都不会被自动覆盖。
  * 「启动时自动检查更新（每天最多一次）」——默认打开，见第八节。
  * 「让 Anki 也自动检查插件更新」——读写 Anki 自己的设置：勾选 / 取消就是改 Anki 的
      「自动检查更新」，插件不会偷偷替你改，打开时按你现有的设置显示。

同一排还有个「打开日志文件」按钮，见第九节。

菜单「工具 → 插件」里选中「标签筛选牌组」，点「配置」改的是「新建」窗口的默认值：
默认父牌组、默认取卡状态、默认是否连没到期的也收、默认顺序、默认上限。
已经建好的牌组不受影响。


八、从 GitHub 更新插件
----------------------

管理窗口底部的「检查更新（GitHub）」：
  * 会在后台去这个插件的公开仓库（github.com/creeperboo/anki-tag-filtered-deck）
    取一下版本号，有新版本才问你要不要下载安装；
  * 装完提示「重启 Anki 生效」；如果磁盘上已经是新版、只是还没重启，只会提醒重启；
  * 查到新版本但还没装的记录，会写进插件数据目录里的 update.json，方便排查。

「启动时自动检查更新（每天最多一次）」打开时，Anki 启动后会顺手检查一次，
一天最多一次；关掉它就只在手动点按钮时检查。

插件只有这一个联网动作（「让 Anki 也自动检查插件更新」用的是 Anki 自己的功能）。
它不会上传你的卡片、牌组或学习记录。


九、出问题时
------------

* 牌组建出来是空的：点「看收不进来的卡」看看——它列出的就是这次收不进来的卡，
  也就是还没到期（而你没勾「连还没到期的也收」）、被暂停 / 搁置、或已经躺在别的
  筛选牌组里的那批。想突击这些卡就用「集中刷…」。
  * 提醒：如果你勾了「连还没到期的也收」，那「没到期」就不是收不进来的原因了，
    这类牌组会把符合条件的卡全收进来；但它是「突击牌组」，不会自动重收，所以
    学完一轮之后牌组会变空——这是正常的，想再刷一遍就用「集中刷…」。
* 交集为空：编辑器会直接提示「没有卡片同时带这些标签」，并列出每个标签各有多少张。
* 插件自己的运行日志写在插件目录里的 user_files\log.txt，管理窗口底部的
  「打开日志文件」可以直接打开它。菜单 / 钩子出问题只会记进这个日志，
  不会再弹 Anki 的「遇到了问题」。
  * 1.5.2 起，后台操作也已经改成交给 Anki 原生结果——以前操作明明成功了也会弹
    「遇到了问题…可能是由某一插件引起」，现在不会了。
* 如果 Anki 弹「遇到了问题，可能是由某一插件引起」：管理窗口底部会自动显示一行
  「最近一次致命异常指向 某个插件 · 时间」（读的是 Anki 的 crash.log）。
  显示本插件就说明是本插件的问题；显示别的插件（比如 interactive_quiz）就与
  本插件无关。
